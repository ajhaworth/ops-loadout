Client ID/Secret only download Houdini, from sidefx.com. Apprentice and Indie are activated or logged into inside Houdini's License Administrator; License server sets hserver on Save. Version pins Install/Update to that major.minor, blank for latest.

How to get a client ID
  1. On sidefx.com open Services → Developers API → “Manage applications authentication”.
  2. Register a new application: any name, client type Confidential, grant type Authorization code, redirect URL https://www.sidefx.com
  3. Copy the Client ID and Client Secret into the fields above.
