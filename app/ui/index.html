SideFX (Houdini downloads)

  1. Open sidefx.com → Services → Developers API → “Manage applications authentication”.
  2. Register a new application: any name, client type Confidential, grant type Authorization code, redirect URL https://www.sidefx.com
  3. Copy the Client ID and Client Secret into the fields below.

Used only to download Houdini. Stored on this Mac in config/sidefx.local. The free Apprentice license is activated inside Houdini itself, no key needed.
