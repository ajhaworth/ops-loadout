# loadout-wm rules (-> ~/.loadout-wm.txt on macOS and Windows). Each listed app is its own workspace: its normal
# windows fill the screen, inset by the padding, and switching to the app (Dock, Cmd-Tab, taskbar) brings them
# forward. Every other window - and a listed app's dialogs, panels and sheets - floats untouched. Edits apply on
# the next window event, no restart. A window of any app snapped flush to a screen half, third or quarter (Swish)
# gets the same padding, using the first rule's padding, so it lines up with the filled ones.
#
# app | title contains | layout | padding
#   app      macOS bundle id or app name, Windows exe name without .exe; case-insensitive. A line for the other
#            platform never matches, so both live here.
#   title    optional; only windows whose title contains it (Blender's main window, not Preferences).
#   layout   fill (default): every normal window fills the screen, stacked.
#            first: only the first window fills; later ones (a compose window) float.
#            split: side-by-side columns, ordered by where they sit; they rebalance when one closes.
#   padding  px around (and, for split, between) windows; default 8, the same as aerospace.toml's inner and
#            outer gaps and the margin macOS's own tiling leaves.
